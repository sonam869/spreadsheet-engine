# Spreadsheet Engine

A mini Excel-like spreadsheet engine built with React.

## Features

- 10x10 Spreadsheet Grid
- Formula Parsing
- Arithmetic Operations
- Dependency Graph (DAG)
- Topological Sorting
- Circular Dependency Detection
- Undo/Redo
- Formula Bar
- Excel-like UI with Tailwind CSS

## Technologies

- React
- Tailwind CSS
- JavaScript

## Run Project

npm install
npm run dev

## Formula Examples

=A1+5
=B1*2
=(A1+B1)/2
